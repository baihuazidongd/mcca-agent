接入新的 IDE

网页型 IDE 可以直接登记。特殊会话协议需要对应适配器；能力只填写实际支持的项目。

任务与监工

记录会跨门户重启保存。会话空闲不等于目标完成；助理可以检查结果后判断下一步。

最近状态变化

浏览器

AI 浏览器使用独立登录配置。个人浏览器可安装连接扩展并允许指定标签页，也可通过已开启的本机调试端口连接。

连接日常使用的 Edge / Chrome

点击生成配对码，在浏览器扩展管理页开启开发者模式，选择“加载解压缩的扩展”，加载结果中的目录。打开扩展填入端口与配对码，然后在目标网页点击“允许当前标签页”。断线后需要重新允许页面。

更完整的点击、填写、iframe、上传下载和请求模拟操作，可由已接入的助理调用。

安卓设备

支持 ADB 可识别的模拟器实例与真机。真机需开启 USB 调试并在设备上授权。可通过 MCCA_ADB 指定已有 adb.exe。

配置本机工具路径

模拟器实例

克隆和参数调整需要实例已停止。其他品牌可先通过 ADB 控制设备，也可在“组件”中登记自定义模拟器配方。录屏、抓包和 APK 分析会话会在下方工具任务中显示；助理可使用已配置的 Frida 环境。

让助理了解整个应用

把下面的 MCP 配置导入 Hermes 或其他支持 MCP 的助理。所有客户端连接同一工作台，工具不会各自再开一份浏览器服务。

可用能力：应用概况、IDE 启停、已适配任务的发布与监工、扩展开关、浏览器及安卓设备控制。

监工委托示例：

检查工作台中我委托的任务，每隔一分钟查看状态。只有完成、失败或需要我处理时通知我；不要重复提交，也不要停止其他任务。会话空闲后先读取结果，再判断目标是否完成。

长期循环由你选定的助理执行。工作台保存任务记录和状态变化，不会在未委托时自动发布任务。

Hermes 长期委托

由 Hermes 原生调度器执行，结果保存在本机。先在“助理接入”连接工作台工具，并保持 Hermes gateway / 调度器运行。暂停委托只暂停后续轮次；停止正在执行的 IDE 任务请使用任务页。
